# Racine — Prototype de suivi client

Prototype réalisé dans le cadre de la thèse professionnelle *"Comment les agences SEO peuvent-elles préserver leur valeur ajoutée face à l'automatisation croissante des tâches par les agents IA ?"*

Il illustre concrètement la recommandation 6.3 : une gouvernance visible, où le client suit en continu l'avancement réel de son compte (maillage interne, briefs, audits, corrections), avec une distinction claire entre ce que l'agent IA a fait seul et ce qu'un consultant a validé ou décidé.

## Déployer ce prototype (GitHub + Vercel, gratuit, sans ligne de commande)

### 1. Mettre le projet sur GitHub

1. Va sur [github.com](https://github.com) et crée un nouveau dépôt (bouton vert **New**), par exemple nommé `racine-dashboard`.
2. Sur la page du dépôt vide, clique sur **uploading an existing file**.
3. Glisse les trois fichiers (`index.html`, `style.css`, `README.md`) dans la zone de dépôt.
4. Clique sur **Commit changes**.

### 2. Déployer sur Vercel

1. Va sur [vercel.com](https://vercel.com) et connecte-toi avec ton compte GitHub.
2. Clique sur **Add New → Project**.
3. Sélectionne le dépôt `racine-dashboard` que tu viens de créer.
4. Vercel détecte automatiquement qu'il s'agit d'un site statique, tu n'as rien à configurer. Clique sur **Deploy**.
5. En quelques secondes, Vercel te donne une URL publique (du type `racine-dashboard.vercel.app`) que tu peux montrer directement à l'oral.

### Pour le jour de la soutenance

Ouvre simplement l'URL Vercel sur ton ordinateur ou ton téléphone, pas besoin de PowerPoint pour cette partie : c'est un vrai outil qui tourne, que tu peux faire défiler en direct devant le jury.
